# App Logo

Place your app logo image file here as `app_icon.png`.

## Requirements:
- **Recommended size**: 1024x1024 pixels
- **Format**: PNG (with transparency if needed)
- **File name**: `app_icon.png`

## After placing the logo:

1. Run `flutter pub get` to install dependencies
2. Run `flutter pub run flutter_launcher_icons` to generate all app icons
3. The tool will automatically create icons for:
   - Android (all density sizes)
   - iOS (all required sizes)
   - Web (192x192, 512x512, maskable versions)
   - Windows
   - macOS
   - Linux

## Note:
The logo should be a square image. The tool will automatically handle different sizes and platforms.
